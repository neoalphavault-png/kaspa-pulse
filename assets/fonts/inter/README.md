# Inter

Inter von Rasmus Andersson und The Inter Project Authors, SIL Open Font License 1.1 (`LICENSE-OFL-1.1.txt`). Die woff2-Dateien stammen aus dem npm-Paket `@fontsource/inter` 5.1.0, Teilmenge latin, Stärken 300, 400 und 500. Die ttf-Dateien sind daraus mit fontTools umgewandelt (für matplotlib), die OFL erlaubt das. Genutzt von `scripts/ph/ph_stil.py` für die PulseHawk-Grafiken.
