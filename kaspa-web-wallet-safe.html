Is a Kaspa Web Wallet Safe?

Last checked on 6 October 2026 against the community wiki at wiki.kaspa.org and the projects' own documentation.

The answer

A Kaspa web wallet is as safe as the browser it runs in. In web mode Kaspa NG keeps your keys in the browser's local storage, the community wiki says so directly, so it suits small amounts you would also carry in a pocket. For anything larger, keep the key on a hardware wallet and let the browser only show balances.

Where the key lives

Kaspa NG in the browser at kaspa-ng.org stores the wallet in the browser's local storage. Anyone or anything that can read that browser profile on your computer gets as close to your key as you are.

Kasware is a browser extension. It keeps the wallet inside the browser profile on your computer, which puts it in the same place as every other extension you have installed.

KasVault works differently. The key stays on a Ledger device, and the web page only asks the device to sign. Its documentation names Chrome and Edge as the browsers that can talk to the Ledger.

Phishing domains

Fake wallet sites copy the look of the real one and change one letter in the address. The only safe start is a directory the Kaspa community maintains, kaspa.org/hodl or the wiki's wallet list, then follow its link. The old web wallet at wallet.kaspanet.io is no longer maintained, so a page that asks you to log in there is not the real thing.

No real wallet asks you to type your seed phrase into a website to verify, upgrade or claim anything. That request is the scam.

Browser extensions

Every extension in your browser can read the pages you open, to some degree, depending on what you allowed when you installed it. A wallet in a browser with many extensions shares its room with all of them. A separate browser profile that holds only the wallet keeps that room small.

Install wallet extensions only from the store listing the project links to itself. Copies with the same name exist.

Watch-only, the safe way to look

If you only want to see your balance, you do not need a key at all. A tool that knows only your public address can show what is there and cannot spend any of it. To track your portfolio and tokens, see kashub.fyi.

When hardware makes sense

When losing the amount would hurt. On a hardware wallet the key never touches the internet-connected computer, the browser or app only passes transactions to the device for signing. Which devices support Kaspa, and which do not, is listed on the wallet page, checked on 6 October 2026.
